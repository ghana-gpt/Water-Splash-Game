# Water Splash Game

A simple browser-based arcade game built with HTML5 canvas, CSS, and JavaScript.

## Features
- Start and restart game flow
- Keyboard and pointer/touch controls
- Increasing difficulty over time
- Score tracking and local best score
- Responsive layout for mobile and desktop

## How to run
1. Clone or download the repository.
2. Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Controls
- Left/Right arrow keys or A/D keys to move
- Mouse/touch movement on the game area also works
